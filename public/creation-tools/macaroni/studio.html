Public-chain privacy boundary

Macaroni keeps the artwork CAR unavailable until the final mint is confirmed. The final metadata address and allocation proof must still pass through a Tezos node and public transaction pool just before confirmation, so an RPC operator, baker, or mempool observer may briefly see that address first. The earlier on-chain collection commitment proves the creator's inventory and the transaction can mint only the already-locked claim.

Stops future purchases. Existing claims still finish; unused reserve returns only after all purchased claims are fulfilled.
