# Cross-App User Stories: Directed Pairs

This file covers every directed pair among the nine Pasta applications. Pairs that are observational or management-only still require validation so users understand the boundary.

### Macaroni -> CH-EASE

As a Creator
I want Macaroni output to be accepted by CH-EASE
So that product work can move across Pasta apps without re-entry or lost provenance.

Acceptance Criteria:

Given a valid Macaroni output and an accessible CH-EASE surface
When the creator initiates the handoff from Macaroni to CH-EASE
Then CH-EASE validates the schema, preserves relationship metadata, shows an inline import result, and refuses to sign or deploy until required CH-EASE fields are complete.

Failure Criteria:

- Malformed package, incompatible contract type, missing authority, or unavailable service produces an in-page error.
- No durable CH-EASE state is mutated until the creator confirms the import or action.
