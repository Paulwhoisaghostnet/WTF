# Puppet Collection Stories

## Creator creates puppet collection

As an Administrator
I want creator creates puppet collection in the actor-backed puppet harness
So that the Pasta ecosystem can be regression-tested without relying on manual creator accounts.

Acceptance Criteria:

Given seeded puppet creator and collector actors with wallet metadata
When the puppet harness executes this step
Then it records route, API, wallet, chain, pinning, and hosted-page evidence appropriate to the step.

Failure Criteria:

- Missing credentials, wrong environment, stale host, unavailable Shadownet RPC, or lost pinning node blocks the suite with an explicit setup error.
