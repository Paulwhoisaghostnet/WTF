# Domain Guides

These notes are intentionally small. Each domain explains what the area does, how it connects to WTF OS, and where the main code lives.

| Domain | Purpose |
| --- | --- |
| [WTF OS](wtf-os.md) | Desktop shell, windows, settings, and admin surfaces. |
| [Identity And Social](identity-and-social.md) | Accounts, profiles, wallet identity, board, messages, W, and Discord-linked surfaces. |
| [Arcade, Console, And Game Studio](arcade-console-game-studio.md) | Playable games, creator submissions, SDK projects, and score/session validation. |
| [Commerce And Wallets](commerce-and-wallets.md) | Marketplace, in-app market, WTF payments, user wallet writes, and platform wallet boundaries. |
| [Wallet Connect Boundary](wallet-connect-boundary.md) | Octez Connect, Beacon fallback, CSP wallet frame rules, and production recovery checks. |
| [Media, TV, And Studio](media-tv-studio.md) | WTF TV, media libraries, creator tools, galleries, and playback/embed surfaces. |
| [Tezos Platform](tezos-platform.md) | Tezos reads/writes, contracts, subdomains, TzKT, and signer boundaries. |
| [Operations](operations.md) | Deployment, environment, health checks, backups, and production ownership boundaries. |
