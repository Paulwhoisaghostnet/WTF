# Macaroni Individual User Stories

Each feature is expressed for Creator, Collector, Curator, Marketplace User, and Administrator, even when a role mostly observes or audits the feature.

## Wallet and network safety

### Creator

As a Creator
I want to perform wallet and network safety with clear progress, validation, and resumable output
So that Macaroni can be used safely inside the Pasta ecosystem.

Acceptance Criteria:

Given creator prerequisites for wallet and network safety are satisfied
When the creator attempts wallet and network safety
Then the system validates inputs, shows status, persists only confirmed durable outputs, and exposes recovery or next-step evidence.

Failure Criteria:

- If required prerequisites are missing, the UI explains the boundary and does not mark the feature complete.
