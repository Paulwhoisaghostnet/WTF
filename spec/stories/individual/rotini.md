# Rotini Individual User Stories

Each feature is expressed for Creator, Collector, Curator, Marketplace User, and Administrator, even when a role mostly observes or audits the feature.

## Layer and trait upload

### Creator

As a Creator
I want to perform layer and trait upload with clear progress, validation, and resumable output
So that Rotini can be used safely inside the Pasta ecosystem.

Acceptance Criteria:

Given creator prerequisites for layer and trait upload are satisfied
When the creator attempts layer and trait upload
Then the system validates inputs, shows status, persists only confirmed durable outputs, and exposes recovery or next-step evidence.

Failure Criteria:

- If required prerequisites are missing, the UI explains the boundary and does not mark the feature complete.
- If network, wallet, pinning, hosting, or indexer state is unavailable, the flow stays recoverable and names the durable artifact already created.
