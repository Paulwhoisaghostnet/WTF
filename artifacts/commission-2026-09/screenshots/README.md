# Commission journey screenshots

This directory contains one 1280×800 desktop capture and one 390×844 mobile capture for each acceptance journey J-01 through J-12.

Regenerate from the production build with:

```bash
npx playwright test tests/playwright/release/commission-screenshots.spec.mjs
```

The screenshot lane proves first-open presentation and readable narrow-layout evidence. The release ledger points to the separate actor, database, and Shadownet proofs for durable behavior.
