# Agent Docs

This folder holds internal project memory that should not clutter the public GitHub documentation surface.

## Live

`.agents/docs/live/` contains files agents should actively read and update:

- `BUG_BOUNTY_BOARD.md`
- `LESSONS_LEARNED.md`
- `WTF_CONSTANTS.md`
- `user-interaction-inventory.md`

## Archive

`.agents/docs/archive/` contains old audits, plans, reports, integration maps, operations notes, contract run logs, and source-local notes that are useful for history but not part of the public docs path.

Keep public product and architecture docs under `README.md`, `ARCHITECTURE.md`, and `docs/`.
