TempleOS

The Temple Operating System, emulated on Ubuntu via QEMU and served through noVNC. First boot drops you into a live CD session — run Install from the prompt to persist TempleOS to the virtual hard disk.

Tip: click the viewport, then use your keyboard.
Press Esc to release the pointer. Your session is shared with every visitor, so keep it clean.
