# Horf horse photography

These are photographs from Wikimedia Commons, displayed by Horf as local, reliable fallbacks when a current-season token has no usable image. Each source file is published under the [CC0 1.0 public domain dedication](https://creativecommons.org/publicdomain/zero/1.0/). The copies in this directory are Wikimedia's 960–1280 px thumbnails; no generated horse illustrations are used.
