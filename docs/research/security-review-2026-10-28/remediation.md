## Preservation and migration boundaries

Root retains body-parser 2.4.0, Multer 2.5.0, Zod 4.6.7, MCP SDK 1.32.0, Hono 4.13.11, Undici 6.29.1/7.30.1/8.12.3 and Vite 8.0.8. Desktop retains electron-builder 26.15.3, scoped global-agent 4.1.3, and the removal of roarr/sprintf-js. The nine desktop dependency graphs change only Electron and fast-uri. No package was downgraded.

The source signer already used Taquito 25.0.0, while its deployed graph used 24.3.0. Source retains 25.0.0. Production retains its existing 24.3.0 and the exact existing bundle; this security patch changes only deployed Zod. Rebuilding the entire signer from current source would have silently promoted unrelated unpublished changes. The old installation remains available for rollback, with keys, environment and journals outside the swapped installation directories. [Dependency verification](evidence/dependency-remediation/verification.json).

The PostgreSQL vendor's conditional extension/reindex/logical-plugin steps do not apply: all three inspected clusters contain only plpgsql, no relevant extensions, logical slots/subscriptions, custom preloads/tablespaces or invalid indexes. Main upgrades through the normal deploy script. The AT host receives only the two database image edits in its existing legacy compose topology. Backups are protected on the hosts; database contents and secrets are excluded from repository evidence.

Mail's newer upstream image still needed a full Debian package revision check: Dovecot upstream-version text or the DockerMailserver tag alone did not prove the backport. The cold backup was independently copied off-host and checksum verified before changing production. Original image, configuration and volumes remain available; rollback must preserve any subsequently accepted mail.

[Reproduction and 16 passing funding/mobile/iPad stories](evidence/mobile-action-overlay-repair.json).

The matching Chromium 156 browser was installed before the successful 16-story run. [Official support history](https://github.com/microsoft/playwright/issues/40117), [current supported image](https://playwright.dev/docs/docker).
