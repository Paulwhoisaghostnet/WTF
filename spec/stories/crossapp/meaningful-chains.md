# Cross-App User Stories: Meaningful Chains

These chains cover the product paths users are expected to run end to end.

## CH-EASE -> Macaroni -> WTF.ME Hosting

As a Creator
I want to move work through CH-EASE -> Macaroni -> WTF.ME Hosting
So that the resulting token, contract, hosted page, or management surface remains coherent across apps.

Acceptance Criteria:

Given each previous step has produced a validated durable artifact
When the creator opens the next app or service in the chain
Then the next step imports the artifact, preserves CIDs/KT1s/relationship metadata, shows missing requirements, and produces its own validation evidence.

Failure Criteria:

- If any step fails, the chain report names the failing app/service and the last durable artifact.
- A later app may not silently reinterpret token products as contract products, or vice versa.
