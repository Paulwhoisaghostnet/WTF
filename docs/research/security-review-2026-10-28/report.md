# WTF security recheck — October 27–28, 2026

The earlier Node/Go and main production dependency fixes remain deployed. The fresh review identifies an exposed mail-service DoS, older PostgreSQL security debt on three running servers, and an unpatched Zod installation in the separate operator signer. Electron now publishes a compatible patch release containing Node's October fixes. Newly indexed `qs` and desktop `fast-uri` findings have narrower or build-only prerequisites.

**Review contract:** recheck announcements since October 22 against current source, dependency locks, published desktop artifacts and actual deployed runtimes; identify concrete correction targets and distinguish new disclosures, older gaps, preserved fixes and unmatched prerequisites. This pass performs review and records findings, not implementation or deployment.

**Baseline:** main and public production commit `0b7b02b25ce74bcb6a3e3cad891c0d9a778504a4`. Checks began October 27 Eastern and continued October 28; receipts retain UTC timestamps. The original dirty checkout was preserved. No install scripts, exploit payloads, server restarts or production writes were used. Evidence includes 30 successful npm audits across 15 lock graphs, a separate Bun-lock registry query, direct runtime interrogation on both hosts, and current desktop release/asset metadata matched to the previous installed-binary attestations.

## Brotli: exploitation news does not erase existing backports

CISA added **CVE-2026-111497** to its Known Exploited Vulnerabilities catalog on **October 27**. That establishes exploitation in the wild, not compromise of WTF. [Official catalog](https://github.com/cisagov/kev-data/blob/develop/known_exploited_vulnerabilities.json), [saved catalog delta](evidence/kev-delta.json).

- Main app and native services retain fixed **Node 22.23.4**; all ten PDS instances retain **24.22.1**. Node's displayed Brotli version need not change when it backports a fix.
- **Current Electron 43.8.3 already contains the Brotli decoder correction.** Electron's tagged build patch links Chromium's Brotli instead of Node's copy. The actual tagged Chromium 150.0.7871.250 decoder contains the upstream permanent-error correction and is byte-identical to the decoder in candidate 43.8.4. Do not label Electron vulnerable to this CVE solely from `Node 24.22.0` or `Brotli 1.2.0`. Other Node fixes and Electron security backports still justify 43.8.4. This is source evidence, not an exploit test. [Build linkage](https://github.com/electron/electron/blob/v43.8.3/patches/node/build_add_gn_build_files.patch), [source comparison receipt](evidence/electron-brotli-backport-proof.json).
- The main app's Debian library **1.0.9-2+deb12u1 is fixed**. Mail still has **1.0.9-2+b6**, below Debian's fixed package. Mail curl links it, but no active mail decoder path accepting attacker Brotli was established; smtpd/Dovecot linkage did not show it. Include this package refresh in mail remediation without calling SMTP a Brotli RCE endpoint. [Debian tracker](https://security-tracker.debian.org/tracker/CVE-2026-111497).
- Both Ubuntu hosts have **1.1.0-2build2**. Ubuntu's tracker says **Needs evaluation**; Debian package floors cannot determine Ubuntu backport status. Some main-host desktop/audio processes load that library, but an attacker-controlled decoding path was not proved. [Ubuntu tracker](https://ubuntu.com/security/CVE-2026-111497).
