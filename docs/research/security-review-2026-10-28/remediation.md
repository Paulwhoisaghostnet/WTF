## Preserved fixes and migration boundaries

No package was downgraded. Independent lock comparison retains MCP SDK 1.32.0, body-parser 2.4.0, Multer 2.5.0, Zod 4.6.7, Hono 4.13.11, Undici aliases 6.29.1 / 7.30.1 / 8.12.3 and Vite 8.0.8. Desktop retains electron-builder 26.15.3, scoped global-agent 4.1.3 and the removal of roarr/sprintf-js. Each desktop graph changes only Electron and fast-uri. [Independent comparison](evidence/dependency-remediation-independent-review.json).

The signer source already used Taquito 25.0.0, while production used 24.3.0. Each retains its existing version; only deployed Zod changed. This avoided silently promoting unrelated unpublished signer changes. The prior installation remains available for rollback; keys, environment and journals remain outside the swapped directories.

PostgreSQL's conditional extension/reindex/logical-plugin cleanup does not apply: all three inspected clusters contain only plpgsql, no affected extensions, logical slots/subscriptions, custom preloads/tablespaces or invalid indexes. Rehearsals preserved 235 tables / 10,766,953 rows in main, 5 / 15 in PLC and 5 / 242 in relay. Main's fresh physical backup was independently manifest-verified before promotion. The AT host received only its two database image edits. A first AT attempt rolled back safely after a receipt-logging defect; data and health were verified, the logging helper was tested, and the corrected retry passed. [Plan and rollback details](evidence/postgres-upgrade/activation-plan.md).

Mail's upstream image still required the Debian security revision: neither the DockerMailserver tag nor Dovecot's upstream-version string proved the backport. A verified cold backup was copied off-host; original images, volumes and configuration are retained. Rollback must preserve subsequently accepted mail. [Operational details](../../../infra/wtfos-mail/SECURITY-UPGRADE.md).

Actual runtime checks also preserve Node 22.23.4 in the main app, PLC, kiln, provider and signer; Node 24.22.1 in all ten PDS instances; and Go 1.26.10 in the relay and both Caddy deployments. Main and AT Caddy remain 2.11.7.
