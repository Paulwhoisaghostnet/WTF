# WTFOS Pinning Stories

## Files are pinned

As a Creator
I want files are pinned through WTFOS-supported storage when I am authorized
So that Pasta outputs remain durable after deploy and export.

Acceptance Criteria:

Given an authorized embedded trusted creator and Pasta artifact set
When the pinning flow processes the artifact set
Then staged bytes, provider pin result, CID, manifest, and recovery status are visible and auditable.

Failure Criteria:

- Unauthorized users do not see wtfOS pinning. Provider stalls identify upload, staging, or provider-pin phase. Recovery retries idempotently by CID or manifest key.
