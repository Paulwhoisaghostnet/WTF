- MonoMEK v1.2 artifact: `ipfs://QmSWnMqZgW7M2jZJA9RyD7RYXokZsS6N7ppE6UWTSTPXcr`
- GROUT Alpha v2 artifact: `ipfs://Qmf1NMGgFx2LhHPXh1z51x7riCR5spHndZxRArxoWsiE3m`

The PDF artifacts are kept as provenance in the appearance provider; browsers
load these local WOFF2 binaries for platform typography.
