# WTF.ME Stories

## Mint pages can be hosted

As a Creator
I want mint pages can be hosted for Pasta output
So that collectors can use hosted collection experiences without guessing which service owns the page.

Acceptance Criteria:

Given a Pasta app has exported a valid page bundle and contract context
When WTF.ME hosts the page
Then the public URL resolves over HTTPS, displays the expected product, preserves branding and chain context, and routes wallet actions through the intended Tezos contract.

Failure Criteria:

- DNS/TLS, missing page artifact, stale contract address, broken wallet bridge, or unavailable indexer is reported as pending or failed, not as live.
